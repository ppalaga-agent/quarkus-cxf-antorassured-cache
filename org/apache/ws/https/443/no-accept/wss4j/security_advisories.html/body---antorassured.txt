<h1>Security Advisories</h1>

<p>
For information on how to report a new security problem please see <a href="https://www.apache.org/security/" class="externalLink">here</a>. </p>

<p>
The following security advisories have been issued for Apache WSS4J&#x2122;: </p>
<ul>

<li><b>2026</b></li>

<ul>

<li><a href="advisories/CVE-2026-85532.txt">CVE-2026-85532</a> - Apache WSS4J: Insufficient Validation of Derived-Key Parameters.</li>

<li><a href="advisories/CVE-2026-87830.txt">CVE-2026-87830</a> - Apache WSS4J: Streaming WS-SecurityPolicy validation may skip element-protection checks.</li>

<li><a href="advisories/CVE-2026-88920.txt">CVE-2026-88920</a> - Apache WSS4J: SAML Sender-Vouches Authentication Bypass.</li>

<li><a href="advisories/CVE-2026-89238.txt">CVE-2026-89238</a> - Apache WSS4J: WSS4J EncryptedHeader child confusion causing wrong protected-header selection.</li>

<li><a href="advisories/CVE-2026-92121.txt">CVE-2026-92121</a> - Apache WSS4J: WS-SecurityPolicy signature checks skipped in the streaming code after an STR-Transform reference.</li>

<li><a href="advisories/CVE-2026-92899.txt">CVE-2026-92899</a> - Apache WSS4J: UsernameToken replay protection bypassed by re-encoding the Nonce.</li>

<li><a href="advisories/CVE-2026-95616.txt">CVE-2026-95616</a> - Apache WSS4J: Unauthenticated denial of service via integer overflow in DER parsing of X.509 certificate extensions.</li>

<li><a href="advisories/CVE-2026-115690.txt">CVE-2026-115690</a> - Apache WSS4J: Replay protection bypassed by concurrent copies of a message.</li>

<li><b>2015</b></li>

<ul>

<li><a href="advisories/CVE-2015-0226.txt.asc">CVE-2015-0226</a> - Apache WSS4J is (still) vulnerable to Bleichenbacher's attack.</li>

<li><a href="advisories/CVE-2015-0227.txt.asc">CVE-2015-0227</a> - Apache WSS4J doesn't correctly enforce the requireSignedEncryptedDataElements property</li>
</ul>
</ul>


<p>
As Apache WSS4J is a library that provides WS-Security functionality to web service stacks such as Apache CXF and Apache Axis, security issues associated with WS-Security tend to be reported to these downstream projects. Therefore the best way to keep an eye on security issues involving WSS4J is to look at the security advisories pages of these projects. </p>

<p>
The security advisory page for Apache CXF is <a href="https://cxf.apache.org/security-advisories.html" class="externalLink">here</a>. In particular, the following security advisories are relevant to users of WSS4J: </p>

<ul>

<li><a href="https://cxf.apache.org/cve-2012-5575.html" class="externalLink">Note on CVE-2012-5575</a> - XML Encryption backwards compatibility attack on Apache CXF.</li>

<li><a href="https://cxf.apache.org/note-on-cve-2011-2487.html" class="externalLink">Note on CVE-2011-2487</a> - Bleichenbacher attack against distributed symmetric key in WS-Security.</li>

<li><a href="https://cxf.apache.org/note-on-cve-2011-1096.html" class="externalLink">Note on CVE-2011-1096</a> - XML Encryption flaw / Character pattern encoding attack.</li>
</ul>
