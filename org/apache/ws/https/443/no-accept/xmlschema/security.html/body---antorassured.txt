<h1>Security and CVE Tracking</h1>
<p>This page tracks known vulnerabilities (CVEs) for Apache XMLSchema.</p>
<p>For reporting a new vulnerability, see <a class="externalLink" href="https://www.apache.org/security/">Apache Security Team</a>.</p></section><section><a id="Apache_XMLSchema_CVEs"></a>
<h1>Apache XMLSchema CVEs</h1>
<ul>
<li><a class="externalLink" href="https://www.cve.org/CVERecord?id=CVE-2026-102495">CVE-2026-102495</a>: Apache XMLSchema: Denial of service through unbounded recursion when resolving schema imports and includes
<ul>
<li>Severity: Low</li>
<li>Affected versions:
<p>- Apache XMLSchema before 2.3.3</p></li>
<li>Description:
<p>Apache XmlSchema doesn't limit how deeply schema imports and includes can be nested, so a malicious schema can make parsing recurse until the stack overflows. This causes a denial of service. Users are recommended to upgrade to version 2.3.3, which fixes this issue.</p></li>
<li>Credit:
<p>This issue was found using Claude agents to study the security of open-source projects (finder)</p></li></ul></li>
<li><a class="externalLink" href="https://www.cve.org/CVERecord?id=CVE-2026-102496">CVE-2026-102496</a>: Apache XMLSchema: Denial of service through deeply nested schema structures
<ul>
<li>Severity: Low</li>
<li>Affected versions:
<p>- Apache XMLSchema before 2.3.3</p></li>
<li>Description:
<p>Apache XmlSchema doesn't limit how deeply schema structures can be nested when it builds its schema model, so a malicious schema can make parsing recurse until the stack overflows. This causes a denial of service. Users are recommended to upgrade to version 2.3.3, which fixes this issue.</p></li>
<li>Credit:
<p>This issue was found using Claude agents to study the security of open-source projects (finder)</p></li></ul></li>
<li><a class="externalLink" href="https://www.cve.org/CVERecord?id=CVE-2026-102497">CVE-2026-102497</a>: Apache XMLSchema: Denial of service through cyclic schema definitions in the schema walker
<ul>
<li>Severity: Low</li>
<li>Affected versions:
<p>- Apache XMLSchema before 2.3.3</p></li>
<li>Description:
<p>The Apache XmlSchema walker (xmlschema-walker) doesn't detect cycles in type derivation, substitution groups, model groups or attribute groups. A malicious schema with such a cycle can make the walker recurse until the stack overflows, causing a denial of service. Users are recommended to upgrade to version 2.3.3, which fixes this issue.</p></li>
<li>Credit:
<p>This issue was found using Claude agents to study the security of open-source projects (finder)</p></li></ul></li></ul></section>        </main>
